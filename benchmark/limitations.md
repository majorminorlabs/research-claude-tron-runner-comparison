# Limitations

- The prompt was intentionally thin, leaving design and implementation decisions to each model. Unrequested features are optional choices; their absence is not automatically a prompt-compliance failure.
- One run per model. This is a controlled one-shot artifact comparison, not a statistical model-performance benchmark. No model-wide quality, superiority, confidence interval or overall score is inferred.
- Authored unit/native suites differ in coverage and assertion granularity. Their counts are not comparable quality scores. Missing lint/typecheck/build/browser scripts remain unavailable.
- Common prompt, logged high effort and client version are established; system/tool-context parity, original hardware/load and hidden requests are not.
- The original 5.5 sessions overlap. Session time includes setup, tools, validation and final reporting; release-ready and compute-only instants are unavailable.
- Token totals include repeated cache reads. They are observed request volume, not unique generated text, context occupancy, costs or invoice-complete activity.
- Production LOC includes comments and blanks, excludes tests/config/output, and is not a complexity or quality score.
- Chrome/SwiftShader smoke is brief; native browsers differ. No native-GPU, measured-FPS, broad-device or long-play ranking is supported. Opus 5 movement-state assertions are unavailable; common portrait smoke uses keyboard, not swipe input.
- Initial suite timeouts and invalid harness attempts are preserved separately from final results. Sonnet 5's denied-storage failure remains unfixed.
- Four real desktop recordings are 1920×1080/60fps; the comparison uses the first 90 continuous seconds at 30fps. Starts, human-input policy, seeds, hardware/browser and graphics settings were not recorded as equivalent. Different scoring/difficulty/health systems make score and survival incomparable.
- Public clips are silent; audio implementation presence is source-confirmed, not an audio-quality rating. Original captured audio remains private.
- Manual review fields are null. Source-inspection concerns are not automatically reproduced bugs.
- Exact historical file-change counts, independently proven release-ready instants, hidden usage and model-version equivalence beyond returned IDs are unavailable.
- Extracts preserve raw counters/hashes/line references; private full conversation logs are not distributed. Local path redactions are documented, so public evidence bytes differ from private originals while game source bytes are preserved.
